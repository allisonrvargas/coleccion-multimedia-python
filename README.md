# 📚 Administrador de Colección de Libros/Películas/Música

## Descripción
Aplicación de consola desarrollada en Python para gestionar colecciones personales de libros, películas y música. Permite organizar, buscar, editar y eliminar elementos de manera estructurada.

## Características

✅ Añadir nuevos elementos (Libros, Películas, Música)
✅ Listar colección completa o filtrada por tipo/género
✅ Buscar elementos por título, creador, género o ID
✅ Editar información de elementos existentes
✅ Eliminar elementos de la colección
✅ Ver estadísticas de la colección
✅ Persistencia de datos en formato JSON
✅ Interfaz de consola amigable con emojis

## Requisitos

- Python 3.7 o superior
- Librería `tabulate`
